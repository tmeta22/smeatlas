# SME Atlas Cambodia

A bilingual directory and map explorer based on the [Open Development Cambodia SME dataset](https://data.opendevelopmentcambodia.net/dataset/sme-dataset). Business records originate from the 2023 YEAC directory. Map results are Google searches and should be verified against the source details. Saved businesses are stored in the visitor's browser.

The site is static. Serve this directory with a local HTTP server to preview it. GitHub Actions deploys the root directory to GitHub Pages when Pages is configured to use GitHub Actions.

Data: Open Development Cambodia, CC BY-SA 4.0.
